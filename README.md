# SurveyHub – Survey and Polling Builder

## Backend Setup
1. Copy `backend/.env.example` to `backend/.env` and update `MONGO_URI` and JWT secrets.
2. Install dependencies and start the server:
   ```bash
   cd backend
   npm install
   npm run dev
   ```

## Frontend Setup
1. Install dependencies and start Vite:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
